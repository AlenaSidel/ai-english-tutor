# English Tutor

[English](README.md) · **Русский** · [Español](README.es.md) · [Português (BR)](README.pt-BR.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

Личный репетитор английского на базе AI-агента ([Claude Code](https://claude.com/claude-code), Codex и других). Агент ведёт уроки, даёт упражнения в файлах, проверяет ответы, отслеживает ошибки и напоминает о повторении.

## Как это работает

1. Вы пишете агенту запрос: «хочу выучить шаблоны для собеседования», «проверь: …», «повторим старые слова».
2. Агент создаёт в вашей папке `users/<имя>/` урок в `lessons/` и задания в `exercises/`.
3. Вы вписываете ответы прямо в файл заданий, после стрелок `→`.
4. Пишете «проверь» — агент добавляет разбор в тот же файл и обновляет журнал прогресса.

Агент в этой папке занимается только английским. На посторонние запросы он мягко предлагает отдохнуть и вернуться к учёбе позже или обсудить ту же тему по-английски. Правила — в разделе «English only» в [`AGENTS.md`](AGENTS.md).

Есть два режима: **общий английский** (повседневные темы) и **профессиональный** (собеседования, встречи с клиентами, работа на английском).

## Структура

```
.
├── AGENTS.md                         # правила для любого агента в этой папке
├── README.*.md                       # переводы: ru, es, pt-BR, zh-CN, ja, ko
├── CLAUDE.md                         # подключает AGENTS.md и README.md для Claude Code
├── GEMINI.md                         # то же для Gemini CLI
├── .claude/skills/
│   ├── english-tutor/SKILL.md        # методика тьютора (без личных данных)
│   └── setup/SKILL.md                # первый запуск: создание папки ученика
├── .agents/skills                    # ссылка на .claude/skills (для Codex, Gemini CLI, Antigravity CLI)
├── templates/                        # пустые заготовки личных файлов, урока и задания
├── prompts/
│   ├── en.md                         # удачные запросы к тьютору
│   └── <код>.md                      # то же на языке ученика, создаёт setup (не попадает в git)
├── LICENSE                           # лицензия MIT
└── users/                            # личные папки учеников (не попадают в git)
    └── <имя>/
        ├── profile.md                # профиль: язык, уровень, цели, профессия
        ├── english-progress.md       # журнал прогресса: ошибки, темы, повторение
        ├── useful-phrases.md         # полезные фразы, встретившиеся по ходу
        ├── lessons/                  # теория по профилю: по файлу на урок
        └── exercises/                # задания к урокам, ответы и разбор
```

## Как оформлены файлы

Образцы всех файлов — в `templates/`. Шаблоны на английском; создавая файлы ученика, уроки и задания, агент пишет подписи (заголовки, шапки таблиц, пояснения) на языке объяснений.

**Уроки и задания.** Файлы урока и заданий называются одинаково: `YYYY-MM-DD-<тема>.md`, например `users/<имя>/lessons/2026-11-18-interview-templates.md` и `users/<имя>/exercises/2026-11-18-interview-templates.md`. Они ссылаются друг на друга.

- Урок (`templates/lesson.md`) — теория: объяснение, шаблоны, примеры, типичные ошибки. Уроки строятся по профилю: примеры — из вашей профессии и опыта.
- Задание (`templates/exercise.md`) — упражнения со ссылкой на урок. После каждого пункта стоит строка `→` для ответа. В конце — раздел разбора (заголовок задан в профиле), он заполняется после проверки.
- Повторение без новой теории — только файл задания с темой `revision`.

**`english-progress.md`** — разделы: текущие приоритеты, слова и фразы, грамматика, повторяющиеся ошибки, что повторить, что уже получается. Здесь же ссылки на уроки и задания.

**`useful-phrases.md`** — таблицы по темам: фраза, перевод, когда использовать.

**`prompts/en.md`** — примеры запросов; таблицы по разделам: промт, что делает, когда использовать. В репозитории только английская версия. При настройке агент переводит её на язык ученика в `prompts/<код>.md` (код ISO 639-1, например `ru.md`); такие файлы остаются локальными. Сохранённые промты добавляются во все версии.

## Начало работы

1. Склонируйте репозиторий.
2. Запустите агента в корне проекта (например, `claude`).
3. Напишите команду первого запуска (см. [таблицу агентов](#какие-агенты-поддерживаются)) или просто «Давай начнём». Агент задаст несколько вопросов — язык, уровень, цели, профессия — и создаст вашу папку `users/<имя>/` из заготовок.
4. Начинайте занятие. Примеры запросов — в [`prompts/en.md`](prompts/en.md), а после настройки — на вашем языке в `prompts/<код>.md` (для русского — `prompts/ru.md`).

Если папки ученика нет, агент сам предложит настройку при первом запросе.

**Вручную, без агента:** создайте папку `users/<имя>/`, скопируйте в неё `templates/profile.md` и заполните поля вместо комментариев `<!-- … -->`. Остальные файлы агент создаст сам на первом занятии.

```bash
mkdir -p users/anna && cp templates/profile.md users/anna/
```

### Какие агенты поддерживаются

| Агент | Инструкции | Скиллы | Первый запуск |
|---|---|---|---|
| [Claude Code](https://claude.com/claude-code) | `CLAUDE.md` → `AGENTS.md`, `README.md` | `.claude/skills/` | `/setup` |
| [Codex](https://developers.openai.com/codex) | `AGENTS.md` | `.agents/skills/` (ссылка) | `$setup` |
| [Cursor](https://cursor.com) | `AGENTS.md` | `.claude/skills/` и `.agents/skills/` | `/setup` в чате Agent |
| [OpenCode](https://opencode.ai) | `AGENTS.md` | `.claude/skills/` и `.agents/skills/` | `@setup` |
| [Antigravity CLI](https://antigravity.google/docs/getting-started) (`agy`) | `AGENTS.md` и `GEMINI.md` | `.agents/skills/` (ссылка) | `/setup` |
| [Gemini CLI](https://geminicli.com) | `GEMINI.md` → `AGENTS.md`, `README.md` | `.agents/skills/` (ссылка) | команды нет |

Проверено в Claude Code и Codex; остальные агенты описаны по документации.

Во всех агентах для первого запуска можно просто написать «Давай начнём». `.agents/skills/` — ссылка на `.claude/skills/`, файлы скиллов одни и те же. Если агент скиллы не нашёл, он откроет их по путям из `AGENTS.md`.

- **Claude Code:** `AGENTS.md` и `.agents/skills/` сам не читает, поэтому нужен `CLAUDE.md`: он подключает `AGENTS.md` и `README.md` через `@`. Скиллы подхватываются из `.claude/skills/` автоматически: агент включает их по описанию, а каждый скилл доступен как слэш-команда (`/setup`, `/english-tutor`).
- **Cursor:** занимайтесь в чате Agent — в остальных режимах правила и скиллы не гарантированы. Cursor видит каждый скилл дважды. Если из-за этого начнутся сбои (скиллы двоятся в списке `/`, срабатывают не те), удалите ссылку `.agents/skills`: Codex, Gemini CLI и Antigravity CLI найдут скиллы по путям из `AGENTS.md`. Папку `.claude/skills/` не удаляйте: в ней настоящие файлы скиллов.
- **Gemini CLI:** с 18 июня 2026 года заменён на Antigravity CLI для бесплатного тарифа и подписок Google AI Pro / Ultra; с платным API-ключом или корпоративной лицензией продолжает работать. Перед загрузкой скилла спрашивает разрешение.

## Персонализация

Все личные данные — в вашей папке `users/<имя>/`, главное — в `profile.md`. Чтобы изменить уровень, цели или язык объяснений, поправьте профиль или попросите агента. Скиллы менять не нужно.

Правила для агентов (`AGENTS.md`) и скиллы написаны по-английски — так их проще поддерживать для учеников с разными родными языками. Объяснения агент даёт на языке из профиля.

Папка `users/` указана в `.gitignore`: ваши уроки, ответы и прогресс не попадут в репозиторий.
